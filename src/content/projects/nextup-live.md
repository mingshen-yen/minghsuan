A full-stack TypeScript application for managing and browsing live music events, built with a React and Vite frontend against an Express and MongoDB backend.

#### ***My Role***

A team project, in which I designed and built the frontend — the interface, the component structure, and the styling.

#### ***Stack***

1. **Frontend**: React with Vite, TypeScript throughout, TailwindCSS for styling
2. **Backend**: Express serving a REST API over MongoDB
3. **Deployment**: hosted on Render, linked above
